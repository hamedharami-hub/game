# Dream Caravan compact transfer

This is the complete working game source and all 23 runtime character sheets in a smaller transfer format. The PNG source sheets and prebuilt standalone HTML are omitted; runtime WebP files are the editable asset source in this copy. Approved face references and compatibility artwork are preserved in their original PNG files.

Run `npm install` then `npm run build`. The full archival source and standalone HTML exist in the original workspace package.
The five approved face reference files are visually lossless-looking WebP transfer copies. Exact original PNGs remain in the archival workspace package.
Screenshots in previews/ are omitted from this transfer; they are not used by the game.

# کاروان رؤیاها · Dream Caravan

بازی آرامِ باغبانی و چیدمان در یک سرزمین بزرگ و پیوسته: دشت، بیشه، آبراه، خانه و میدان همه بخش‌های همان سرزمین‌اند. گل بکار، کنار آب قدم بزن، درخت روح را پیدا کن و گوشه‌های دشت را به سلیقهٔ خودت بساز. مسیر اجباری، مأموریت، ارز یا هزینهٔ ساخت وجود ندارد.

## شروع بازی

- [بازی مستقل](release/play.html): فایل را با مرورگر باز کن. ذخیره در حالت فایل به پشتیبانی همان مرورگر وابسته است.
- شخصیت‌ها فرشته و گوراستاخ هستند؛ همراهان محلی‌اند و بازی چندنفره یا چت هوش مصنوعی ندارد.
- ذخیره در مرورگر و بر اساس نمایهٔ آدرس صفحه جدا می‌شود؛ حساب کاربری یا همگام‌سازی ابری نیست.

## کارهای اصلی

- **کاشت:** دکمهٔ «کاشت» را بزن، نوع گل را انتخاب کن و روی خاک باغچهٔ زنده کلیک یا لمس کن. این گل‌ها حدود یک تا دو دقیقه رشد می‌کنند؛ با چیدنشان همان جای کاشت چرخهٔ تازه‌ای را شروع می‌کند.
- **ساخت آزاد:** دکمهٔ «ساخت آزاد» را باز کن و درخت، درخت روح، گل تزئینی، گروه گل تزئینی، باغچهٔ زندهٔ فعلی، خانهٔ باغی، کلبه، آلاچیق، پل یا چاه را برگزین. گل‌های این فهرست تزئینی‌اند و رشد یا برداشت ندارند. باغچهٔ زنده فقط یکی است؛ آن را می‌توانی جابه‌جا کنی، اما باغچهٔ تازه‌ای ساخته نمی‌شود. پیش‌نمایش را با ماوس یا لمس روی چمن ببر؛ با کلیدهای جهت‌دار یا WASD هم می‌توانی جایش را تنظیم کنی و وقتی صحنه فعال است با Enter بسازی. نقطهٔ سبز قابل استفاده است؛ نقطهٔ قرمز با آب یا سازه‌ای دیگر تداخل دارد. پیش‌نمایش نزدیک لبهٔ زمین درون مرز امن نگه داشته می‌شود. برای جابه‌جایی سازهٔ خودت، آن را در فهرست سازه‌ها برگزین یا روی خودش بزن، سپس جای تازه را مشخص کن. سازهٔ انتخاب‌شده را با دکمه‌های چرخش یا R بچرخان و با «برداشتن» یا Delete حذف کن؛ گل‌های کاشته‌شده و زمان رشدشان با جابه‌جایی باغچه حفظ می‌شوند.
- **همراه‌ها:** سلام کن، بنشین، با هم قدم بزن، پرواز دونفره را آغاز یا تمام کن یا ظاهر شخصیت‌ها را عوض کن. با لمس زمین، WASD یا کلیدهای جهت‌دار حرکت کن؛ اسکرول یا چرخ ماوس دوربین را زوم می‌کند.

## طبیعت و ساخت‌وساز

جویبار پهن و پیچانِ بیشه به آبشار کوتاهی می‌رسد؛ برق‌های متحرک آب و صدای آرام محیط به آن جان می‌دهند. درخت روح با تنه و قلب نورانی و چراغک‌های شناور کنار جای نشستن قرار دارد. باد، باران و تغییر نور دشت با زمان بازی فعال پیش می‌روند. با روشن‌بودن کاهش حرکت، جلوه‌های متحرک آرام یا متوقف می‌شوند.

ساخت‌وساز روی چمن آزاد است، به شرطی که تمام پایهٔ سازه داخل زمین بماند و با آب یا بنای دیگر تداخل نداشته باشد. گل‌ها و باغچهٔ اصلی را می‌توان هر زمان جابه‌جا کرد؛ رشدشان به زمان واقعی ادامه می‌یابد، حتی وقتی بازی بسته است. تغییرات و ظاهر انتخاب‌شده در ذخیرهٔ محلی می‌مانند.

## توسعه و بررسی

به Node.js 24 نیاز است. از ریشهٔ مخزن:

```sh
npm ci
npm run dev -- --port 4174
```

سرور توسعه در همان پنجره فعال می‌ماند. در یک پنجرهٔ دیگر، بررسی‌ها را اجرا کن:

```sh
npm test
npm run build
npx playwright install --with-deps chromium
npx playwright test
```

Playwright پیش‌نمایش build را روی پورت 4175 راه می‌اندازد. خروجی مستقل build در `dist/play.html` ساخته می‌شود؛ پس از بررسی تغییرات، آن را برای انتشار در `release/play.html` کپی کن.

جزئیات نتیجهٔ آخرین بررسی باید در [گزارش اعتبارسنجی](docs/VALIDATION.md) ثبت شود. فهرست دارایی‌های تصویری در [مانیفست هنر](docs/ASSET_MANIFEST.json) و مرز اتصال با ارشناز در [راهنمای یکپارچه‌سازی](docs/ARSHNAZ_INTEGRATION.md) آمده است.

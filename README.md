# کاروان رؤیاها · Dream Caravan

بازی مرورگری ساختن، پرورش و کشف در دنیای دوشاخ‌ها؛ همراه فرشته و گوراستاخ، فرمانروای این سرزمین. کد واقعی بازی، تصاویر تأییدشده و منابع طراحی برای ادامهٔ کار در ابزارهای دیگر در این مخزن قرار دارند.

**برای ابزار طراحی/کدنویسی دیگر:** ابتدا [AGENTS.md](AGENTS.md)، [راهنمای انتقال](docs/HANDOFF.md)، [هویت تصویری و داستان](docs/ART_DIRECTION.fa.md) و [طراحی جهان](docs/WORLD_DESIGN.fa.md) را بخوانید. [قالب تحویل تغییرات](docs/CHANGE_REQUEST.md) مسیر بازگشت کار برای بازبینی است.

- [نسخهٔ قابل‌بازی بدون نصب](release/play.html): دانلود کنید و با مرورگر باز کنید؛ عکس پیش‌نمایش بازی نیست.
- [فهرست تصاویر و ترکیب‌ها](docs/ASSET_MANIFEST.json): سه رنگ مو × سه لباس برای هر شخصیت، با هشت جهت.
- [مرجع کلاسیک](public/art/characters.png)، [لباس سفر](public/art/look-traveler-brown.webp)، [لباس روح و ستاره](public/art/look-celestial-white.webp).
- [اتصال به ارشناز](docs/ARSHNAZ_INTEGRATION.md): بازی مستقل است؛ انتشار مخزن بازی، سایت ارشناز را خودکار به‌روز نمی‌کند.

## شروع سریع

Node 24 پیشنهاد می‌شود. از ریشهٔ مخزن:

```sh
npm ci
npm run dev -- --port 4174
npm test
npm run build
npx playwright install --with-deps chromium
npx playwright test
```

Playwright پیش‌نمایش ساخت‌شده را خودش راه می‌اندازد. خروجی مستقل در dist/play.html است؛ برای انتشار تازه، پس از تست آن را به release/play.html کپی کنید. ساخت معمولی بیرون از مخزن چیزی نمی‌نویسد.

## چگونه بازی کنیم؟

روی زمین بزنید یا با WASD حرکت کنید؛ اسکرول زوم می‌کند. با «نقشه» وارد یکی از شش محیط شوید. «باغ ما» ابزار کاشت را باز می‌کند؛ گل را انتخاب و روی خاک باز بزنید. رشد هنگام بسته‌بودن بازی هم ادامه دارد. از گل شکوفا یا چشمهٔ بیشه نور جمع کنید. «ساخت و گسترش» سازه، جابه‌جایی، گسترش منطقه، رنگ مو و لباس هر دو شخصیت را در اختیار می‌گذارد. دکمهٔ نمای نزدیک/باز برای دیدن محیط و شخصیت‌هاست. «پرواز و شناوری» یا F ارتفاع شخصیت‌ها را تغییر می‌دهد. داستان آغازین با جمع‌کردن سه ماده و ساخت اختراع پیش می‌رود.

هر حساب چیدمان محلی مستقل دارد؛ اتصال واقعی پاداش تسک‌ها، Firebase، AI هنگام بازی، داخل ساختمان‌ها و مأموریت‌های پویا هنوز پیاده نشده‌اند. شخصیت‌ها تصاویر ۲٫۵بعدی هشت‌جهته‌اند، نه مدل سه‌بعدی اسکلت‌دار. انتخاب لباس/مو رایگان است و پیشرفت را تغییر نمی‌دهد.

# کاروان رؤیاها — باغ خاموش

نمونهٔ مستقل مرورگری از فصل اول در دنیای دوشاخ‌ها. فرشته با انتخاب شخصی برای دیدن گوراستاخ، فرمانروای این سرزمین، فرود آمده است.

## اجرای آسان بدون نصب

فایل `dist/play.html` بازی واقعی و مستقل است. آن را دانلود کنید و با Chrome، Edge یا Firefox باز کنید. همهٔ کد و تصاویر داخل همین فایل هستند؛ اینترنت یا سرور لازم نیست. تصویرهای `previews/` فقط عکس ثابت‌اند. ذخیرهٔ بازی در حالت فایل به سیاست مرورگر وابسته است؛ در صورت محدودبودن ذخیره، پیام نمایش داده می‌شود.

## اجرای توسعه

Node.js 22.12 یا جدیدتر:

```sh
cd /workspace/Arshiam/dream-caravan
npm ci --cache /tmp/caravan-npm-cache
npm run dev -- --port 4174
```

`npm run build` خروجی مستقل را در `dist/` می‌سازد. برای بررسی همان خروجی: `npm run preview -- --port 4174`.

## بازی

برچسب باغ خاموش بالای ورودی آن قرار دارد. دوربین فرشته را دنبال می‌کند؛ با اسکرول می‌توان زوم کرد. روی مواد، کارگاه یا دکمهٔ مقصد بزن؛ فرشته حرکت می‌کند و پس از رسیدن، تعامل خودکار انجام می‌شود. دکمهٔ قدم بعدی کار بعدی را نشان می‌دهد. کلیک روی زمین یا کلیدهای جهت/WASD حرکت آزاد است و دکمهٔ تعامل یا E هم در دسترس است.

سه ماده جمع کن، در کارگاه فانوس شناور یا جوانهٔ نور بساز و نمای سه‌بعدی چرخان آن را ببین و کنار باغ خاموش از آن استفاده کن. ظاهر باغ مطابق انتخاب تغییر می‌کند. گوراستاخ دنبال فرشته می‌آید و گفتگوی اولیه دارد. دفتر سفر شامل شروع دوباره با تأیید است.

## محدودهٔ نمونه و محدودیت‌ها

- محیط سه‌بعدی با شخصیت‌های تصویری چهارجهته (۲٫۵بعدی) از طرح‌های تأییدشده؛ شخصیت‌ها هنوز مدل سه‌بعدی یا اسکلت انیمیشن ندارند.
- تصویرهای تأییدشدهٔ شخصیت‌ها مبنای صورت و لباس در بازی و گفتگو هستند.
- داده با کلید نسخه‌دار `dream-caravan:garden:v1` فقط روی همین مرورگر ذخیره می‌شود. خطای ذخیره به کاربر اعلام می‌شود.
- منابع آزمایشی هستند؛ حساب Firebase، امتیاز ارشناز، پرداخت، تولید محتوای AI و ارسال پاداش واقعی متصل نیستند. هوش مصنوعی در طراحی تصویرها استفاده شده است؛ اختراع‌ها در زمان بازی دو دستور ثابت دارند.
- هیچ داده‌ای از تسک‌های ارشناز تغییر نمی‌کند.
- شیت‌های شخصیت منابع طراحی‌اند و مجوز انتشار آن‌ها باید مطابق انتخاب صاحب پروژه باشد.

## اتصال پاداش و ذخیرهٔ ابری در آینده

این نسخه از داخل ارشناز باز می‌شود؛ اتصال حساب و امتیازهای واقعی هنوز انجام نشده است. ورود مشترک باید با سازوکار رسمی احراز هویت انجام شود؛ توکن را در URL قرار ندهید. سرویس پاداش سمت سرور باید شناسهٔ یکتای هر رخداد معتبر تسک/مرور را ثبت کند و افزایش موجودی را اتمی و تکرارناپذیر انجام دهد. ذخیرهٔ محلی این نمونه نباید منبع قابل‌اعتماد پاداش واقعی باشد.

## بررسی

```sh
npm test
npm run build
# سرور نمونه را روی 4174 اجرا کنید؛ chromium نصب‌شده لازم است.
npx playwright test
```

آزمون مرورگر هر دو مسیر ساخت را در موبایل و دسکتاپ، تعامل خودکار، بارگذاری مجدد، عدم امکان ساخت زودهنگام و شروع دوباره بررسی می‌کند. فایل مستقل پس از بارگذاری اولیه، بدون هیچ درخواست وابستهٔ شبکه اجرا شده و کلیک مستقیم روی ماده بررسی شده است. پروتکل file در مرورگر مدیریت‌شدهٔ این محیط مسدود است؛ بازکردن مستقیم آن روی دستگاه کاربر در این محیط آزمایش نشده است. مسیر Chromium در `playwright.config.ts` برای محیط فعلی تنظیم شده است.

## باغ مشترک داخل ارشناز

ورودی جدید: منو ← رشد ← «باغ و خانه» (`/app/caravan`). بازی هنگام ورود به همین صفحه بارگذاری می‌شود؛ بخش‌های قبلی باغ و جزیره حفظ شده‌اند. خروجی مستقل از `dist/play.html` در `../public/dream-caravan/index.html` کپی می‌شود. بعد از تغییر سورس بازی، ابتدا در همین پوشه `npm ci` و `npm run build`، سپس در ریشهٔ ارشناز `npm run build` اجرا کنید و خروجی public را همراه سورس ثبت کنید. HTML بزرگ بازی وارد پیش‌بارگذاری PWA نمی‌شود و مسیر آن از fallback برنامه مستثناست.

دکمهٔ «باغ ما» ابزار کاشت را باز می‌کند. بذر را انتخاب کنید و روی زمین بزنید؛ برای دسترسی دقیق یا با صفحه‌کلید، «انتخاب دقیق جای کاشت» را باز کنید. برای جابه‌جایی، گیاه را انتخاب کنید، «جابه‌جایی» و سپس جای خالی را بزنید. رشد و آبیاری آن حفظ می‌شود.

سه گونهٔ آزمایشی با زمان رشد ۶، ۱۰ و ۱۵ دقیقه، چهار مرحلهٔ بذر، جوانه، بوته و شکوفه دارند. زمان واقعی مرورگر حتی هنگام بسته‌بودن بازی حساب می‌شود. آبیاری اختیاری هر سه دقیقه، ۲۵٪ مدت رشد را جلو می‌برد؛ گیاه‌ها خشک نمی‌شوند. باغ از ۴×۴ با دو گیاه شکوفا به ۶×۶ و با شش گیاه شکوفا به ۸×۸ گسترش می‌یابد. گسترش محل گیاه‌های قبلی را تغییر نمی‌دهد.

درون ارشناز ذخیرهٔ محلی با شناسهٔ حساب جدا می‌شود؛ این جداسازی، احراز هویت یا ذخیرهٔ ابری نیست. در نمونهٔ مستقل بدون حساب از کلید قبلی استفاده می‌شود؛ ذخیره‌های قدیمی خودکار با باغ خالی سازگار می‌شوند. بستن صفحه پیشرفت را پاک نمی‌کند؛ «شروع دوباره» پس از تأیید، باغ و سفر را پاک می‌کند. اتصال به امتیاز تسک‌ها، Firebase و سفارش پویا برای مردم هنوز مرحلهٔ بعد است. ساخت خانه در نسخهٔ ۵ اضافه شده است.

یادداشت محیط بررسی: حامل native نسخهٔ SWC 1.16.13 در این محیط به مجوز پوشهٔ cache خطا داد. ساخت ارشناز و تست‌های رابط با بستهٔ رسمی SWC 1.15.3 در node_modules محیط اجرا شدند؛ package.json و lockfile ارشناز تغییر نکردند.

## سرزمین گسترده — نسخهٔ ۵

نقشهٔ تازه شش مقصد دارد: باغ مشترک، گلخانهٔ پیوند، خانهٔ ما، میدان دوشاخ‌ها، بیشهٔ روح و نیایشگاه عشق. همه قابل بازدیدند؛ مسیرها محیط‌ها را به هم وصل می‌کنند و نقشه امکان سفر سریع دارد. هر منطقه دکمهٔ «امکانات منطقه» دارد. در باغ، «تجهیز باغ» پروژه‌های نیمکت و برکه را باز می‌کند.

برای شروع به بیشه بروید: چشمه هر ۶۰ ثانیه سه نور می‌دهد. از هر گل شکوفا نیز می‌توان هر سه دقیقه دو نور برداشت کرد؛ گل حذف یا کم‌سن نمی‌شود. هزینه‌ها از موجودی نور بازی کم می‌شوند و ساخت یک پروژه دوباره پاداش یا هزینه ایجاد نمی‌کند. نور، ارز آزمایشی محلی است و از تسک‌های ارشناز نمی‌آید.

- باغ: ۴×۴، ۶×۶، ۸×۸، ۱۰×۱۰، ۱۲×۱۲. شرط گسترش به ترتیب ۲، ۶، ۱۲ و ۲۰ گیاه شکوفاست. مختصات و سن گیاه‌های قبلی حفظ می‌شود.
- گلخانه: فعال‌سازی ۸ نور؛ داشتن یک گل ماه و یک گل آفتاب شکوفا و ۴ نور، سوسن ستاره را برای کاشت در باغ باز می‌کند. این پیوند یک دستور ثابت است؛ تولید آزاد AI نیست.
- خانه: ساخت آشیانه ۶ نور، خانهٔ گسترده ۱۲ نور، قصر ۲۰ نور. ظاهر بنا در هر مرحله تغییر می‌کند؛ داخل بنا هنوز قابل ورود نیست.
- میدان: چراغ‌ها ۶ نور و آبنما ۱۰ نور؛ مردم دوشاخ و غرفه‌های بازار در محیط حضور دارند. گفتگوی پویا و سفارش شخصی NPC هنوز پیاده نشده است.
- بیشه: چشمهٔ نور و پل قابل‌ساخت با ۵ نور.
- نیایشگاه: سه حلقهٔ قابل‌بیداری، هرکدام ۵ نور، با تغییر نمای بنا.
- باغ: نیمکت ۳ نور و برکه ۵ نور.

پیشرفت منطقه‌ها، موجودی، پروژه‌ها، خانه، کشف گونه و برداشت گل‌ها ذخیره می‌شوند. ذخیرهٔ قدیمی بدون پاک‌کردن گیاه‌ها مهاجرت می‌کند. رشد و دوره‌های برداشت از ساعت دستگاه استفاده می‌کنند؛ برای اقتصاد واقعی به ساعت و ثبت رخداد سمت سرور نیاز خواهد بود. این نسخه شبیه‌سازی زندگی کامل، برخورد فیزیکی با بناها یا جستجوی مسیر ندارد؛ حرکت آزاد و تعامل مشخص برای هر منطقه دارد.

آزمون‌های نسخهٔ ۵ علاوه بر سفر قدیمی، تمام شش منطقه، خرج‌کردن منابع، ساخت قصر و پروژه‌ها، پیوند گیاه، برداشت، حفظ ذخیره و نمایش موبایل/دسکتاپ را بررسی می‌کنند. درخت‌های محیط گسترده با InstancedMesh ساخته شده‌اند تا تعداد درخواست‌های رسم افزایش زیادی نداشته باشد.

بهینه‌سازی باغ بزرگ: اجزای گیاه‌ها بر اساس هندسه و رنگ در InstancedMesh گروه‌بندی می‌شوند؛ باغ ۱۲×۱۲ می‌تواند ۱۴۴ گیاه داشته باشد. تغییر سن یا جابه‌جایی، گروه‌های رسم را به‌روز می‌کند و اطلاعات فردی گیاه‌ها در ذخیره باقی می‌ماند. رندر هنگام نمایش پنجره‌های گفتگو به پنج فریم در ثانیه محدود می‌شود؛ هدف حرکت در محیط سی فریم در ثانیه است و نرخ واقعی به دستگاه بستگی دارد. سایه‌های ثابت به‌جای محاسبهٔ دوباره در هر فریم، هنگام تغییر صحنه به‌روز می‌شوند.

## نسخهٔ ۶ — محیط‌های مستقل و پرواز

ناحیه‌ها دیگر همگی در یک زمین مشترک رسم نمی‌شوند. هر ناحیه گروه مستقل و زمین بزرگ خودش را دارد؛ با نقشه یا درگاه می‌توان وارد ناحیهٔ دیگر شد. هنگام ورود، گروه‌های دیگر و اجزای باغ قبلی از رندر پنهان می‌شوند. هندسهٔ سبک آن‌ها در حافظه می‌ماند؛ این نسخه بارگذاری شبکه‌ای جداگانه یا حذف کامل حافظهٔ ناحیه‌ها ندارد.

درخت‌های عمومی پرتعداد حذف شده‌اند؛ هر ناحیه درخت‌های کمتر با تنهٔ خمیده، تاج‌های متفاوت و برخی تاج‌های نورانی دارد. بلورها، خطوط جادویی، حلقه‌های روح و ذرات نور به ناحیه‌ها اضافه شده‌اند. میدان چهارده دوشاخ دارد که آرام حرکت و شناوری می‌کنند.

در باغ روی خاکِ بازشده بزنید: ابزار کاشت باز می‌شود و اولین گل کاشته می‌شود. دکمهٔ «باغ ما» نیز از هر منطقه مستقیماً به باغ برمی‌گردد. ورود به ابزار همیشه در حالت کاشت شروع می‌شود؛ برای جابه‌جایی ابتدا گیاه، سپس دکمهٔ جابه‌جایی و خانهٔ خالی را انتخاب کنید. بخش «انتخاب دقیق جای کاشت» برای انتخاب با صفحه‌کلید یا صفحهٔ کوچک حفظ شده است.

دکمهٔ «پرواز و شناوری» یا کلید F، فرشته را بالا می‌برد و گوراستاخ را همراهش معلق می‌کند. حرکت افقی هنگام پرواز فعال است؛ دوباره همان دکمه را بزنید تا فرود بیایند. بال‌های نورانی، حلقهٔ زیر پا و سایهٔ روی زمین به این حالت واکنش دارند. هنگام چیدن باغ، شخصیت‌ها پایین می‌آیند تا انتخاب زمین راحت بماند. شخصیت‌های اصلی همچنان تصویرهای چهارجهته هستند و پرواز، مدل اسکلتی سه‌بعدی نیست.


## نسخهٔ ۷ — محیط شخصی و گسترش

زمین اولیهٔ باغ قطر ۵۲ و دیگر ناحیه‌ها قطر ۶۴ واحد دارد. هر ناحیه مستقل تا ۲۰ بار با نور بازی گسترش می‌یابد؛ هر مرحله شعاع را چهار واحد زیاد می‌کند و چهار جای ساخت می‌افزاید (۸ تا ۸۸ جای شخصی). این سقف برای کنترل مصرف موبایل است. باغچهٔ کاشت همچنان قواعد رشد و ۱۲×۱۲ قبلی را دارد؛ گسترش منطقه، جای باغچه و سن گیاه‌ها را تغییر نمی‌دهد.

«ساخت و گسترش» در بالای همهٔ محیط‌ها: نوع سازه و شمارهٔ جای آن را انتخاب کنید. انتخاب سازهٔ موجود و سپس جای خالی، جابه‌جایی رایگان است؛ پاک‌کردن ارز را برنمی‌گرداند. بلور، طاق، حوض و کوشک هرکدام هندسهٔ واقعی متفاوت دارند. گسترش، مرز روشن زمین و تراس تازه را تغییر می‌دهد. ۱۱ پروژهٔ تازهٔ موضوعی نیز افزوده شده‌اند؛ پروژه‌ها فعلاً اثر بصری دارند و مأموریت یا درآمد خودکار ندارند.

بذر چیدمان در حساب تازه از شناسهٔ حساب و در مهمان از عدد تصادفی ساخته می‌شود و پس از نخستین ذخیره ثابت می‌ماند. زمین‌ها، سازه‌ها و رنگ موی گوراستاخ با کلید محلی جداگانهٔ هر حساب نگهداری می‌شوند؛ هنوز بین دستگاه‌ها همگام نمی‌شوند. ذخیرهٔ قدیمی سازگار است. موی سفید پیش‌فرض است و موی قهوه‌ای از همان بخش قابل مقایسه و انتخاب است.

### آلبوم شخصیت‌ها
از «دفتر سفر ← آلبوم شخصیت‌ها» به ۲۴ کارت تصویری دسترسی داری: شش حالت فرشتهٔ کوچک، شش گوراستاخ کوچک و شش حالت بزرگسالانه برای هرکدام. روی کارت بزن تا بزرگ باز شود؛ فیلتر شخصیت/نما و دریافت مجموعه هم در دسترس است. تصاویر ثابت‌اند و ورود کارت حرکت نرم دارد. آلبوم تغییری در پیشرفت یا انتخاب لباس بازی ایجاد نمی‌کند.
